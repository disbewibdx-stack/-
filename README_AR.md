# Jordan Royale — حزمة البداية

هذه ملفات بداية لمشروع Unity وليست APK جاهزة. تحتوي على حركة لاعب، كاميرا خلفية، عصا لمس، وسلاح تجريبي يصيب أهداف التدريب. لا يوجد أونلاين أو تسجيل دخول أو متجر حقيقي في هذه المرحلة.

## المتطلبات
- كمبيوتر Windows أو macOS أو Linux.
- Unity Hub وإصدار Unity LTS يدعم Android.
- أثناء تثبيت Unity اختر Android Build Support مع Android SDK & NDK Tools و OpenJDK.
- بناء لعبة 3D بهذا النوع من الهاتف وحده غير عملي؛ تحتاج كمبيوتر للبناء والتجربة.

## إعداد أول مشهد
1. افتح Unity Hub وأنشئ مشروع `3D (URP)` باسم `JordanRoyale`.
2. انسخ مجلد `Assets/Scripts` من هذه الحزمة إلى مجلد المشروع.
3. أنشئ أرضية من `GameObject > 3D Object > Plane`.
4. أنشئ `Capsule` باسم `Player`، أضف `CharacterController` وسكربت `ThirdPersonPlayer`.
5. على `Main Camera` أضف `OrbitCamera`، اسحب اللاعب إلى خانة `Target` في السكربت، واسحب الكاميرا إلى `Camera Transform` في سكربت اللاعب.
6. أنشئ هدفًا أمام اللاعب باستخدام `Cube` أو `Capsule` مع Collider، وأضف إليه `PracticeTarget`.
7. أضف `SimpleWeapon` إلى كائن اللاعب أو كائن فارغ، ثم اربط `Main Camera` بخانة `Aim Camera`.
8. اضغط Play. على الكمبيوتر استخدم WASD أو الأسهم للحركة، وحرك الماوس لتوجيه الكاميرا، واضغط زر الماوس الأيسر لإطلاق النار.

## تحكم الموبايل
1. أنشئ Canvas بنظام `Screen Space - Overlay` وتأكد من وجود `EventSystem`.
2. أضف صورتين دائريتين أسفل اليسار: خلفية العصا ومقبضها.
3. أضف `VirtualJoystick` إلى كائن الخلفية واربط حقلي `Background` و`Handle`، ثم اربط هذا الكائن بحقل `Joystick` في `ThirdPersonPlayer`.
4. أضف زر إطلاق على يمين الشاشة، وأضف `GameHUD` إلى كائن UI فارغ. اربط الزر بالدالة `GameHUD.FirePressed` واربط السلاح في حقل `Weapon`.
5. على الهاتف، اسحب إصبعك في الجهة اليمنى لتدوير الكاميرا.

## إخراج APK تجريبي
1. افتح `File > Build Profiles` أو `File > Build Settings` حسب إصدار Unity.
2. اختر Android ثم `Switch Platform`.
3. في Player Settings اختر Package Name مثل `com.yourstudio.jordanroyale` واجعل اتجاه الشاشة Landscape.
4. فعّل ARM64، ثم اختر Build لإنشاء APK.

## مراحل التطوير القادمة
- لوبي رئيسي وخزنة ومتجر عملات تجريبية.
- شخصية أصلية بكمامة وملابس قابلة للتبديل.
- نظام حسابات وحفظ بيانات على خادم.
- غرف خاصة وأصدقاء ثم مباراة أونلاين بخادم مخصص.
- خريطة مستوحاة من محافظات الأردن وأنماط مصنف وكلاش وكلاسيك.
